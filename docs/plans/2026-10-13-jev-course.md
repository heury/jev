# Jev 결정 모델 강의 구현 계획

**목표:** 딥러닝 경험자가 NVIDIA GPU 서버에서 Jev 호환 모델을 학습하고 검증할 수 있는 한국어 Slidev 강의와 Jupyter 실습을 만든다.

**구성:** 110분 강의, CPU 확률 실습, 단일 NVIDIA GPU 학습 실습, 로컬 HTTP API 검증. Jev는 비공개 API 모델이며 학습 대상은 Unsloth로 변환한 Qwen이다. 모든 노트북은 단독 파일로 실행 가능하게 작성한다.

**기술:** Slidev, Python 3.11/3.12, Unsloth 2026.10.4, Hugging Face datasets, nbformat/nbclient.

1. 공식 문서와 decision.py, 공식 노트북, 데이터 카드를 교차 확인하고 sources.md에 출처를 기록한다.
2. slides.md에 개념, 수식, 스키마, 학습, 평가, 서빙, 실습과 해설을 작성한다. npm build로 검증한다.
3. 01 노트북: 합성 확률의 softmax, 온도 보정, NLL/Brier/ECE, 보류 정책을 CPU에서 실행한다.
4. 02 노트북: 설치/환경 검사 → 원본 데이터 행 단위 중복 제거 및 분할 → 전후 평가 → 보정 → 테스트 → 저장/재로딩 → 예측 비교. 실제 GPU 실행 여부를 명확히 기록한다.
5. 03 노트북: 세 질문 유형의 응답 계약 검증, 실제 API 호출, 지연시간/라벨 평가. 기본 오프라인 모드는 합성 응답 검사만 수행하며 실제 추론으로 표시하지 않는다.
6. 노트북 스키마/구문 검사와 CPU 실행, API 클라이언트의 로컬 테스트 서버 검증, Slidev 빌드/화면 검사 후 README에 결과와 제한을 기록한다.

**완료 기준:** 강의와 실습 순서가 연결되고, CPU 경로가 실행되며, GPU 경로에는 실제 공식 API, 데이터 분리, 체크포인트 재로딩, 환경 기록 코드가 있다. GPU 미실행을 성공으로 표시하지 않는다.
